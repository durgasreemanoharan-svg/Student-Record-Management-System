# Student Record Management System

A beginner-friendly console-based project developed using Core Java.

## Features
- Add a student record
- View all student records
- Search for a student using student ID
- Update student details
- Delete a student record
- Validate inputs and prevent duplicate student IDs

## Technologies and Concepts
- Java
- Classes and Objects
- Encapsulation
- ArrayList
- Methods
- Scanner for user input
- Loops and switch-case
- Conditional statements

## Requirements
- JDK 8 or later

## How to Run
1. Open this folder in a terminal or command prompt.
2. Go into the `src` folder.
3. Compile the program:
   `javac Main.java`
4. Run the program:
   `java Main`

## Project Structure
```
Student_Record_Management_System/
├── src/
│   └── Main.java
└── README.md
```

## Note
This is an in-memory console application. Records remain available while the program is running and are cleared when the application exits.
